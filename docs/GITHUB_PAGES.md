GitHub Pages Configuration Guide

This beatbook is now set up to be published via GitHub Pages!

## Setting Up GitHub Pages

To enable GitHub Pages for this repository:

1. Go to your repository on GitHub: https://github.com/NewsAppsUMD/jour329w_fall2025

2. Click **Settings** (top right of the repo)

3. In the left sidebar, click **Pages** (under "Code and automation")

4. Under "Build and deployment":
   - **Source**: Select "Deploy from a branch"
   - **Branch**: Select "main" and "/docs" folder
   - Click **Save**

5. GitHub will deploy your site. You'll see a URL like:
   `https://NewsAppsUMD.github.io/jour329w_fall2025/`

## Files Location

All beatbook files are now in the `/docs` folder at the repository root:
- `index.html` - Main beatbook interface
- `script.js` - Application logic
- `style.css` - Styling
- `data.json` - Data for the beatbook

## Updating the Site

When you push changes to the `/docs` folder, GitHub will automatically rebuild and deploy the site within a few minutes.

## Access Your Live Beatbook

Once deployed, your beatbook will be live at:
`https://NewsAppsUMD.github.io/jour329w_fall2025/`
